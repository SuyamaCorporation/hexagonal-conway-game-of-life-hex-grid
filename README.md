# 六角形グリッド Conway 生命ゲーム（Hex Game of Life）

正六角形グリッド上でConwayの生命ゲームを実行するシミュレーター。各セルは隣接する6セルとの関係で誕生・生存・死滅が決まり、正方形グリッドとは異なる独特のパターンが展開する。生存ルール（B/S表記）をプリセットから選択でき、B2/S34（Hex推奨）やB2/S3（標準Conway変形）など複数のルールを試せる。カンバス上をクリック・ドラッグしてセルを手書き入力することも可能。世代数・生存セル数をリアルタイム表示。

## 使い方

「ランダム」でランダム初期状態を生成し「開始」でアニメーション開始。カンバスをクリックして手動でセルを配置後に開始することもできる。ルールや速度はサイドパネルで変更可能。
